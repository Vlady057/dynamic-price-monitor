# Dynamic Price Monitor

A Python-based price monitoring tool that uses Selenium to collect product data from an e-commerce website, stores price history in SQLite, and detects price changes between checks.

The project demonstrates practical skills in **web automation, web scraping, database integration, and automated testing**.

---

## Features

* Search products using Selenium WebDriver
* Extract product title, price, and URL
* Store products in SQLite
* Store complete price history with timestamps
* Detect price increases and decreases
* Calculate absolute and percent
